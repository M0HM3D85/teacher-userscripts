# WhatsApp Communication Manager | مدير التواصل عبر واتساب

> مدير متابعة وتواصل داخل WhatsApp Web يساعد على تنظيم القروبات والعضوية وسجل التواصل واستيراد البيانات من ملفات Excel/CSV.

**الإصدار الحالي:** `0.5.0`

## ما الذي يقدمه السكربت؟

يضيف السكربت أدوات تنظيم فوق WhatsApp Web لتسهيل العمل على قوائم الطلاب أو جهات الاتصال والقروبات، مع الاحتفاظ بسجل يساعد على معرفة ما تم ومراجعة البيانات المستوردة قبل استخدامها.

## أبرز المزايا

- متابعة القروبات من داخل WhatsApp Web.
- تدقيق العضوية ومقارنة القوائم ضمن الوظائف المدعومة.
- سجل للتواصل يساعد على متابعة العمليات المنفذة.
- استيراد ذكي لملفات Excel وCSV العامة.
- التعامل مع المحادثات والقروبات ضمن واجهة موحدة قدر الإمكان.
- قراءة بيانات الاتصال المتاحة داخل WhatsApp Web لدعم سير العمل.

## طريقة الاستخدام

1. ثبّت السكربت عبر Tampermonkey.
2. افتح WhatsApp Web وانتظر اكتمال تحميل الواجهة والمحادثات.
3. افتح لوحة مدير التواصل التي يضيفها السكربت.
4. استورد الملف المطلوب أو استخدم أدوات القروبات والمتابعة.
5. راجع الأسماء والأرقام والوجهات قبل تنفيذ أي عملية تواصل جماعية.

## الموقع المدعوم

- `https://web.whatsapp.com/*`

## ملاحظات تشغيلية

- يعتمد السكربت على بنية WhatsApp Web، لذلك قد تحتاج بعض الوظائف إلى تحديث إذا غيّر WhatsApp الواجهة أو واجهات البيانات الداخلية.
- راجع بيانات المستلمين دائمًا قبل أي إرسال جماعي.
