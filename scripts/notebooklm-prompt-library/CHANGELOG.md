## v1.1.4 — 2026-10-25
- **السبب المثبت:** سياسة Trusted Types في NotebookLM تمنع إسناد نص HTML إلى `ShadowRoot.innerHTML`، وكانت توقف السكربت قبل إنشاء واجهته.
- إزالة جميع استخدامات HTML sinks النصية واستبدالها بإنشاء عقد DOM دون تجاوز سياسة الحماية.

- اجتياز اختبارات Chromium باستخدام CSP يفرض Trusted Types، تشمل فتح وتعديل ونسخ وإعادة ربط الواجهة وحماية مدخلات المستخدم من تفسير HTML.
- الحالة: إصدار تجريبي بانتظار تأكيد المستخدم داخل الموقع الفعلي.

## v1.1.3 — 2026-10-25

- توفير موضع احتياطي داخل الصفحة وإعادة تركيب الزر واللوحة بعد تغييرات Angular.
- اختبارات Chromium ناجحة: التشغيل، الفتح، التعديل، النسخ، الحفظ، إعادة بناء DOM، وحقن خطأ في التهيئة.
