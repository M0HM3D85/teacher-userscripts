# سجل التغييرات

## v1.1.3 — 2026-10-25
- إضافة زر وصول مدمج بجانب حقل عنوان الدفتر بدل اشتراط ظهوره فوق مربع الدردشة.
- عرض محتوى المكتبة داخل اللوحة عند فتحها؛ الزر ليس عنصرًا عائمًا.
- إنشاء زر البدء قبل تحميل القوالب حتى لا يؤدي خطأ بيانات أو تهيئة إلى اختفاء المدخل تمامًا.
- توثيق مرحلة فشل التهيئة عبر `document.documentElement.dataset.nlplStatus` و`nlplStage`.
- توفير موضع احتياطي داخل الصفحة وإعادة تركيب الزر واللوحة بعد تغييرات Angular.
- اختبارات Chromium ناجحة: التشغيل، الفتح، التعديل، النسخ، الحفظ، إعادة بناء DOM، وحقن خطأ في التهيئة.
- لم يؤكد المستخدم بعد ظهور الإصدار v1.1.3 في موقع NotebookLM الفعلي.

## v1.1.2 — 2026-10-25
- تجاوز حاوية إدخال الرسائل ذات الارتفاع المقيد وربط واجهة المكتبة مباشرة بلوحة المحادثة.
- استخدام وجود `section.chat-panel` دون اعتماد على تسمية مربع الرسالة.
- تحسين الاستعادة بعد إعادة بناء Angular للوحة المحادثة وانتظار تحميلها.
- إضافة علامة تشخيصية بسيطة إلى `document.documentElement.dataset.nlplStatus`.
- اجتاز فحص JavaScript واختبارات متصفح محاكاة للعرض والتحكم والنسخ والتخزين وإعادة الارتباط.
- الإصدار على فرع التطوير؛ بانتظار تجربة المستخدم داخل NotebookLM الفعلي.

## v1.1.1 — 2026-10-25
- إصلاح عدم العثور على مربع المحادثة العربي المسمى «مربّع طلب البحث».
- استخدام محددات المحادثة المؤكدة من تقرير الواجهة مع إبقاء خيار احتياطي.
- إدراج المكتبة قبل `div.input-group` في تدفق منطقة المحادثة، دون زر عائم.
- اجتياز فحص بناء JavaScript وتجربة إدراج وإعادة إدراج في محاكاة DOM.
- بانتظار تجربة المستخدم داخل موقع NotebookLM الفعلي.

## v1.1.0 — 2026-10-25
- دمج واجهة مكتبة البرومبتات داخل منطقة المحادثة بدل زر عائم.
- الاحتفاظ بقوالب المستخدم وقيم المتغيرات السابقة.
- تهيئة التعامل مع إعادة بناء عناصر واجهة NotebookLM.
- **حالة:** نسخة تطوير بانتظار تقرير تشخيصي من صفحة NotebookLM الفعلية بسبب عدم ظهور المكتبة لدى المستخدم.
