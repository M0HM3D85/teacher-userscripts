# مكتبة البرومبتات الذكية — NotebookLM

**الإصدار المحفوظ:** v1.1.1 (نسخة تطوير/اختبار، وليست إصدارًا نهائيًا معتمدًا).

مكتبة برومبتات داخل صفحة محادثة NotebookLM، مصممة لتسهيل حفظ النصوص المتكررة وإعادة استخدامها مع متغيرات قابلة للتعبئة مثل عنوان الدرس، الوحدة، عدد الأسئلة، الصف والدرجة.

## التثبيت
1. ثبّت إضافة Tampermonkey في المتصفح.
2. افتح الملف [notebooklm-prompt-library.user.js](./notebooklm-prompt-library.user.js) بنسخته الخام أو انسخه إلى سكربت جديد داخل Tampermonkey.
3. افتح دفترًا داخل https://notebooklm.google.com/ لتظهر المكتبة داخل قسم المحادثة إذا توافق الهيكل الحالي للواجهة مع مكتشف موضع الإدراج.

## الإمكانيات
- قوالب متعددة، تعديل/إضافة/حذف وبحث.
- متغيرات ديناميكية بصيغة `{{عنوان_الدرس}}` وتعبئتها من حقول.
- معاينة النص الناتج ونسخه، دون إرسال الطلب إلى NotebookLM تلقائيًا.
- حفظ القوالب والقيم في مساحة Tampermonkey المحلية.
- استيراد وتصدير مكتبة القوالب بصيغة JSON.
- قالب أولي لأسئلة Microsoft Forms يعتمد حصريًا على المصدر المحدد.

## حالة التطوير والمشكلة المفتوحة
- النسخة 1.1.0 غيّرت العرض من زر عائم إلى دمج داخل منطقة المحادثة.
- النسخة 1.1.1 أصلحت اكتشاف حقل المحادثة العربي عبر محددات `section.chat-panel textarea.query-box-input` و `.input-group` وفق تقرير تشخيص المستخدم، دون تغيير تخزين القوالب.
- تم اختبار هذا الدمج على **واجهة محاكاة**؛ لم يثبت حتى الآن نجاحه على واجهة NotebookLM الفعلية.
- وصل تقرير DOM الفعلي بتاريخ 2026-10-25، وأظهر أن خانة الدردشة تحمل تسمية «مربّع طلب البحث»؛ كانت النسخة السابقة تستبعدها خطأ.
- اجتاز الإصدار 1.1.1 فحص صياغة JS واختبارات واجهة محاكاة من واقع التقرير، لكن ظهور المكتبة في حساب المستخدم لم يُتحقق منه بعد.
- لذلك لا تنشر هذه النسخة في `main` أو GreasyFork على أنها مستقرة قبل التحقق داخل الموقع الحقيقي.

## الخصوصية
السكربت لا يقرأ محتوى الدفاتر أو يرسل البرومبت تلقائيًا. القوالب تحفظ محليًا داخل Tampermonkey؛ تصدير JSON يتم بأمر المستخدم.
