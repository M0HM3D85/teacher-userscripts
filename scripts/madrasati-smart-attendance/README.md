# Madrasati Smart Attendance | التحضير الذكي لمدرستي

> أدوات أسرع وأكثر وضوحًا لتسجيل حضور الطلاب في مدرستي مع التحضير الجماعي والتعديل الفردي والبحث والفرز والإحصاءات.

**الإصدار الحالي:** `0.2.1`

## ما الذي يقدمه السكربت؟

يعمل السكربت داخل صفحة تحضير الحصة في مدرستي ويضيف أدوات تساعد المعلم على التعامل مع قوائم الطلاب الكبيرة وتقليل النقرات المتكررة أثناء تسجيل الحضور.

## أبرز المزايا

- تحضير جميع الطلاب دفعة واحدة.
- تعديل حالة طالب واحد عند الحاجة دون فقد بقية العمل.
- البحث السريع داخل قائمة الطلاب.
- فرز الأسماء والحالات لتسهيل المراجعة.
- تصفية الحضور حسب الحالة.
- مؤشرات وإحصاءات مختصرة تساعد على التأكد من اكتمال التحضير.
- التراجع عن التغييرات المدعومة قبل اعتمادها عند الحاجة.
- الحفاظ على آلية العمل الأصلية في مدرستي مع إضافة أدوات مساعدة فوقها.

## طريقة الاستخدام

1. ثبّت السكربت من GreasyFork عبر Tampermonkey.
2. افتح صفحة تحضير الحصة في مدرستي.
3. استخدم أدوات التحضير الجماعي أو البحث والفرز حسب الحاجة.
4. راجع الحالات قبل اعتماد الحضور نهائيًا داخل مدرستي.
