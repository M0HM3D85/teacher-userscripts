# Changelog

جميع التغييرات المهمة في **Madrasati Smart Attendance | التحضير الذكي لمدرستي** تُسجل هنا.

## [0.3.2] — 2026-09-18

- اعتماد الإصدار النهائي بعد التجربة الفعلية في مدرستي.
- تكبير بطاقات الإحصائيات وتحويلها إلى فلاتر تفاعلية قابلة للضغط.
- إضافة نسخ أسماء الطلاب مباشرة من بطاقات الحالات.
- فصل الإحصاءات إلى: حاضر، غائب بعذر، غائب بدون عذر، متأخر بعذر، متأخر بدون عذر، غير محدد.
- إضافة مؤشر جاهزية الحضور مع عدد المحددين والمتبقي قبل الحفظ.
- إضافة «غير المحددين ← حاضر» ووضع «الاستثناءات» و«التالي غير المحدد».
- إضافة نطاق واضح للعمليات الجماعية: كل الطلاب أو الصفوف الظاهرة فقط.
- إضافة تأكيد للعمليات الحساسة وسجل تراجع لآخر خمس عمليات جماعية.
- إضافة فرز حسب الأولوية مع البحث والفرز الأبجدي والفلاتر الحالية.
- إضافة تقرير حصة لحظي مع نسخ كامل، نسخة واتساب، CSV، وطباعة/PDF.
- تحسين استخراج بيانات الحصة: الحصة، المادة، الفصل، الوقت، والتاريخ المقروء بدل قيم `dateTicks` الخام.
- إصلاح التقاط عناوين جدول الطلاب ضمن معلومات الحصة في التقرير.
- زيادة وضوح ألوان صفوف الحضور وإضافة شريط لوني جانبي للحاضر والغائب والمتأخر وغير المحدد.
- إضافة اختصارات `/` و`Alt+A` و`Alt+Z` و`Alt+N`.
- تحسين أداء العمليات الجماعية ومنع التحديثات المتكررة أثناء الحلقة.
- الحفاظ على دعم وضعي التحضير الجماعي الأولي وتعديل الحضور المحفوظ.
- لا يضيف الإصدار تخزينًا تاريخيًا للحضور أو قائمة متابعة أو مقارنة بالحصة السابقة.

## [0.2.1] — Baseline import

- اعتماد الملف الذي سلّمه المطور كخط أساس رسمي للمشروع.
- توحيد بيانات المؤلف والحقوق وروابط المشروع عند الحاجة.
- لا يُعد توحيد الهوية تغييرًا وظيفيًا في السكربت.
