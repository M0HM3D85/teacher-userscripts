# Microsoft Forms Smart Enhancer - محسن Microsoft Forms الذكي

> أدوات تنظيم وإدارة إضافية لـ Microsoft Forms تشمل الفهرسة الصارمة والبحث المباشر والتدقيق والإدارة الجماعية للأسئلة.

**الإصدار الحالي:** `1.0.5`

## ما الذي يقدمه السكربت؟

يضيف السكربت طبقة تنظيم فوق Microsoft Forms لتسهيل الوصول إلى النماذج والعمل على الأسئلة بكفاءة أكبر، خصوصًا عند وجود عدد كبير من النماذج أو الأسئلة.

## أبرز المزايا

- فهرسة تلقائية مخفية للنماذج دون إزعاج واجهة المستخدم.
- مسح الفهرس السابق قبل إعادة البناء لتقليل التكرار والنتائج القديمة.
- بحث مباشر للوصول إلى النموذج المطلوب بسرعة.
- إبقاء أدوات المساعدة الثانوية مطوية لتقليل ازدحام الواجهة.
- قوالب إعدادات ضمن الوظائف التي يدعمها السكربت.
- تدقيق الأسئلة وإدارة جماعية للعمليات المدعومة.
- تحسين سير العمل مع الحفاظ على واجهة Forms الأصلية قدر الإمكان.

## طريقة الاستخدام

1. ثبّت السكربت عبر Tampermonkey.
2. افتح Microsoft Forms من صفحة التصميم المدعومة.
3. اترك الفهرسة التلقائية تعمل في الخلفية.
4. استخدم البحث للوصول إلى النموذج المطلوب أو افتح أدوات التدقيق والإدارة بحسب المهمة.
5. راجع أي عملية جماعية قبل اعتماد التغييرات النهائية.
