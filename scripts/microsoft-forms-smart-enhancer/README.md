# Microsoft Forms Smart Enhancer - محسن Microsoft Forms الذكي

> أدوات تنظيم وإدارة إضافية لـ Microsoft Forms تشمل الفهرسة والبحث، متابعة الاستجابات الجديدة، البحث المباشر عن المستجيبين، قوالب الإعدادات، والتدقيق والإدارة الجماعية السريعة للأسئلة.

**الإصدار الحالي:** `1.3.9`

## ما الذي يقدمه السكربت؟

يضيف السكربت طبقة تنظيم وإدارة فوق Microsoft Forms لتسهيل الوصول إلى النماذج ومتابعة الاستجابات الجديدة والعمل على الأسئلة بكفاءة أكبر، مع تسريع الوصول إلى استجابة الطالب مباشرة من صفحة المراجعة.

## أبرز المزايا

- فهرسة محفوظة وآمنة للنماذج بدل إعادة مسح جميع المجلدات تلقائيًا عند كل دخول.
- بحث مباشر للوصول إلى النموذج المطلوب بسرعة.
- متابعة الاستجابات الجديدة مع شارات على النماذج والمجلدات وملخص وفلاتر مدمجة.
- اعتماد العدد الحالي كنقطة بداية عند تفعيل المتابعة لأول مرة حتى لا تُعد الاستجابات القديمة جديدة.
- الاستفادة بشكل سلبي من `GetRespCounts` الذي يرسله Forms نفسه دون Polling شبكي دوري إضافي، مع إبقاء زر «فحص الآن» للفحص اليدوي.
- زر صريح «تمت مراجعة الاستجابات» داخل صفحة مراجعة الإجابات، مع الاحتفاظ بالاستجابات التي تصل أثناء جلسة المراجعة كاستجابات جديدة.
- بحث مباشر داخل `Grading_ReviewAnswers` بالاسم المكتوب في سؤال الاسم أو الاسم المؤسسي أو البريد أو رقم الاستجابة.
- القفز مباشرة إلى استجابة الطالب عبر `ridx` بدل المرور المتكرر على «الشخص التالي».
- استخراج الاسم المكتوب من `answers` الموجودة أصلًا في طلب `/responses` الذي يرسله Forms، بدون إنشاء طلب شبكي إضافي للبحث.
- إعطاء أولوية للاسم الذي كتبه الطالب، مع استخدام الاسم المؤسسي والبريد كبدائل، وتجنب اعتبار اسم المستخدم قبل `@` اسمًا حقيقيًا للطالب.
- إبقاء بيانات فهرس المستجيبين في الذاكرة فقط وعدم حفظ أسماء الطلاب أو بريدهم في `localStorage` أو `sessionStorage`.
- طي القوالب تلقائيًا عند دخول صفحة Forms الرئيسية باستخدام زر Forms الأصلي، مع إبقاء إمكانية فتحها يدويًا أثناء الجلسة.
- قوالب إعدادات محفوظة لتطبيق إعدادات النماذج بسرعة.
- تدقيق الأسئلة والبحث والتصفية والتحديد الذكي.
- إدارة جماعية للنقاط وحالة «مطلوب».
- تكرار وحذف جماعي للأسئلة مع التحقق من نجاح العملية.
- إعادة ترتيب سريعة للأسئلة المحددة إلى البداية أو النهاية أو موضع مخصص.
- تنفيذ مباشر وسريع لعمليات الإدارة المدعومة عبر Forms API بدل فتح كل سؤال وتنفيذ العملية واحدًا واحدًا.
- تحقق من حالة النموذج بعد العمليات وتحديث واجهة Forms تلقائيًا عند الحاجة.
- عزل أدوات محرر الأسئلة عن صفحة `Grading_ReviewAnswers` لتقليل تغييرات DOM وتحسين التوافق مع أدوات التصحيح الأخرى مثل عارض المرفقات.
- الحفاظ على واجهة Forms الأصلية قدر الإمكان مع أدوات مساعدة مدمجة وقابلة للطي.

## طريقة الاستخدام

1. ثبّت السكربت عبر Tampermonkey.
2. افتح Microsoft Forms من صفحة التصميم المدعومة.
3. استخدم الفهرس المحفوظ مباشرة، واضغط «إعادة الفهرسة» فقط عند الحاجة إلى تحديث خريطة النماذج والمجلدات.
4. راقب شارات الاستجابات الجديدة على النماذج والمجلدات أو استخدم فلتر «لديها استجابات جديدة».
5. من صفحة مراجعة الإجابات استخدم مربع البحث للعثور على الطالب بالاسم المكتوب أو الاسم المؤسسي أو البريد أو رقم الاستجابة ثم انتقل إليه مباشرة.
6. بعد الانتهاء من مراجعة الردود اضغط «تمت مراجعة الاستجابات» من صفحة مراجعة الإجابات.
7. افتح أدوات المحسن داخل محرر النموذج للبحث والتدقيق والتحديد الجماعي.
8. حدد الأسئلة المطلوبة ثم اختر العملية الجماعية المناسبة.
9. راجع رسالة التأكيد قبل العمليات الحساسة مثل الحذف أو إعادة الترتيب.
