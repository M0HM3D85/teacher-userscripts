# Microsoft Forms Smart Enhancer - محسن Microsoft Forms الذكي

**الإصدار الحالي:** `1.0.5`

محسن شامل لـ Microsoft Forms: فهرسة تلقائية مخفية وصارمة، بحث مباشر للنموذج، قوالب إعدادات، تدقيق وإدارة جماعية للأسئلة.

## المواقع المستهدفة

- `https://forms.cloud.microsoft/Pages/DesignPageV2.aspx*`
- `https://forms.office.com/Pages/DesignPageV2.aspx*`
