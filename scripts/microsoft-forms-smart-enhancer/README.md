# Microsoft Forms Smart Enhancer - محسن Microsoft Forms الذكي

> أدوات تنظيم وإدارة إضافية لـ Microsoft Forms تشمل الفهرسة والبحث والتدقيق والإدارة الجماعية السريعة للأسئلة.

**الإصدار الحالي:** `1.2.0`

## ما الذي يقدمه السكربت؟

يضيف السكربت طبقة تنظيم وإدارة فوق Microsoft Forms لتسهيل الوصول إلى النماذج والعمل على الأسئلة بكفاءة أكبر، خصوصًا عند وجود عدد كبير من النماذج أو الأسئلة.

## أبرز المزايا

- فهرسة تلقائية مخفية للنماذج مع مسح الفهرس السابق قبل إعادة البناء.
- بحث مباشر للوصول إلى النموذج المطلوب بسرعة.
- إخفاء عناصر القوالب غير المطلوبة لتقليل ازدحام الصفحة.
- قوالب إعدادات محفوظة لتطبيق إعدادات النماذج بسرعة.
- تدقيق الأسئلة والبحث والتصفية والتحديد الذكي.
- إدارة جماعية للنقاط وحالة «مطلوب».
- تكرار وحذف جماعي للأسئلة مع التحقق من نجاح العملية.
- إعادة ترتيب سريعة للأسئلة المحددة إلى البداية أو النهاية أو موضع مخصص.
- تنفيذ مباشر وسريع لعمليات الإدارة المدعومة عبر Forms API بدل فتح كل سؤال وتنفيذ العملية واحدًا واحدًا.
- تحقق من حالة النموذج بعد العمليات وتحديث واجهة Forms تلقائيًا عند الحاجة.
- الحفاظ على واجهة Forms الأصلية قدر الإمكان مع أدوات مساعدة قابلة للطي.

## طريقة الاستخدام

1. ثبّت السكربت عبر Tampermonkey.
2. افتح Microsoft Forms من صفحة التصميم المدعومة.
3. اترك الفهرسة التلقائية تعمل في الخلفية عند صفحة النماذج.
4. افتح أدوات المحسن داخل محرر النموذج للبحث والتدقيق والتحديد الجماعي.
5. حدد الأسئلة المطلوبة ثم اختر العملية الجماعية المناسبة.
6. راجع رسالة التأكيد قبل العمليات الحساسة مثل الحذف أو إعادة الترتيب.
