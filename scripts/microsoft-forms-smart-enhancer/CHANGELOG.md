# Changelog

جميع التغييرات المهمة في **Microsoft Forms Smart Enhancer - محسن Microsoft Forms الذكي** تُسجل هنا.

## [1.4.1] — إصلاح تتبع الاستجابات بعد انخفاض أو إعادة ضبط الردود

- إصلاح حالة كان فيها نموذج يحتوي استجابات حالية لكن لا يظهر عليه بادج «جديدة» لأن المحسن جعل العدد المنخفض الحالي خط أساس رغم عدم وجود مراجعة صريحة.
- إذا انخفض عدد الردود بعد ضغط المستخدم «تمت مراجعة الاستجابات»، يستمر السلوك المحافظ ويُخفض خط الأساس إلى العدد الحالي.
- إذا انخفض عدد الردود دون مراجعة صريحة، يُعاد خط الأساس إلى صفر حتى لا تضيع الاستجابات الجديدة عند مسح الردود القديمة أو إعادة ضبطها.
- إضافة ترحيل تلقائي لسجلات الإصدارات السابقة التي تحتوي `adjustedDownAt` بدون `reviewedAt` وتصحيح خط أساسها مرة واحدة.
- الحفاظ على تتبع الاستجابات الجديد، البحث المباشر بالاسم المكتوب والمؤسسي، القفز عبر `ridx`، وطي القوالب وبقية مزايا v1.3.9.

## [1.3.9] — البحث المباشر عن المستجيبين وطي القوالب تلقائيًا

- إضافة بحث مباشر داخل صفحة `Grading_ReviewAnswers` بالاسم المكتوب أو الاسم المؤسسي أو البريد أو رقم الاستجابة.
- دعم القفز المباشر إلى استجابة الطالب عبر `ridx` بالاعتماد على ترتيب الاستجابة في قائمة `/responses` بدل التنقل المتكرر بين الأشخاص.
- فك حقل `answers` الموجود في استجابات Forms واستخراج الاسم المكتوب من سؤال الاسم من نفس الطلب الأصلي دون إضافة طلب شبكي جديد.
- إعطاء الاسم الذي كتبه الطالب أولوية في العرض والبحث، مع إبقاء الاسم المؤسسي والبريد ورقم الاستجابة كبدائل.
- اكتشاف الحالات التي يكون فيها `responderName` مجرد اسم المستخدم قبل `@` وعدم اعتباره اسم الطالب الأساسي.
- إبقاء فهرس المستجيبين وبيانات الهوية في الذاكرة فقط دون تخزين أسماء الطلاب أو بريدهم في `localStorage` أو `sessionStorage`.
- طي قسم القوالب تلقائيًا عند دخول صفحة Forms الرئيسية باستخدام زر Forms الأصلي مع السماح بفتحه يدويًا أثناء الجلسة.
- الحفاظ على متابعة الاستجابات الجديدة وآلية «تمت مراجعة الاستجابات» وعمليات Forms API الجماعية السريعة السابقة.

## [1.3.6] — متابعة الاستجابات الجديدة وتحسين التوافق مع صفحة المراجعة

- إضافة متابعة الاستجابات الجديدة على مستوى النماذج والمجلدات مع عدادات وشارات وفلاتر مدمجة.
- اعتماد خط أساس محلي للمراجعة بحيث لا تُعد الاستجابات القديمة جديدة عند التفعيل الأول.
- إضافة زر «تمت مراجعة الاستجابات» داخل صفحة مراجعة الإجابات مع الحفاظ على الاستجابات التي تصل أثناء جلسة المراجعة كجديدة.
- إزالة Polling الشبكي الدوري لأعداد الاستجابات والاستفادة من `GetRespCounts` الذي يرسله Forms نفسه، مع إبقاء «فحص الآن» يدويًا.
- تحويل الفهرسة الكاملة إلى فهرسة محفوظة وآمنة بدل إعادة مسح جميع المجلدات تلقائيًا عند كل دخول.
- إضافة مهلة بين المجلدات عند إعادة الفهرسة اليدوية وإيقاف المسح عند ظهور رسائل الضغط من Forms.
- عزل Editor Enhancer عن `Grading_ReviewAnswers` لتقليل تغييرات DOM داخل صفحة التصحيح.
- إزالة حلقة Mutation غير المقصودة في شريط المراجعة وتحسين التوافق مع سكربت عارض المرفقات والتصحيح السريع.
- الحفاظ على عمليات Forms API الجماعية السريعة الموجودة في v1.2.0.

## [1.2.0] — Fast bulk actions

- اعتماد التنفيذ المباشر السريع لعمليات Microsoft Forms الجماعية عبر Forms API.
- تسريع تغيير النقاط وحالة «مطلوب» للأسئلة المحددة بدل فتح كل سؤال على حدة.
- تسريع تكرار الأسئلة المحددة مباشرة عبر طلبات الإنشاء الأصلية في Forms.
- تسريع الحذف الجماعي مع إبقاء تأكيد واحد قبل العملية والتحقق من رجوع عدد الأسئلة المتوقع.
- اعتماد إعادة ترتيب مباشرة وسريعة للأسئلة المحددة مع دعم البداية والنهاية والموضع المخصص.
- الحفاظ على ترتيب الأسئلة المحددة النسبي عند نقلها ككتلة واحدة.
- التحقق من نجاح عمليات الترتيب والتعديل عبر API قبل إعلان اكتمال العملية.
- تحديث واجهة Forms تلقائيًا بعد العمليات التي لا تعكس التغيير بصريًا مباشرة.
- تحسين التقاط رؤوس جلسة Forms اللازمة للكتابة مع عدم اعتبار Authorization غير الفعلي شرطًا للنجاح.
- استخدام XMLHttpRequest في عمليات الكتابة المباشرة لمطابقة سلوك Forms الأصلي بشكل أقرب.
- تحسينات على الفهرسة والبحث وإخفاء القوالب وقوالب الإعدادات والتدقيق والإدارة الجماعية للأسئلة.

## [1.0.5] — Baseline import

- اعتماد الملف الذي سلّمه المطور كخط أساس رسمي للمشروع.
- توحيد بيانات المؤلف والحقوق وروابط المشروع عند الحاجة.
- لا يُعد توحيد الهوية تغييرًا وظيفيًا في السكربت.
