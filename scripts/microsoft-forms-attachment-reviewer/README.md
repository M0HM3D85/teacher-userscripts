# Microsoft Forms - عارض المرفقات والتصحيح السريع

> بيئة عملية لتصحيح مرفقات الطلاب داخل Microsoft Forms مع عرض الملفات والتنقل السريع والاختصارات وأدوات التكبير والتدوير.

**الإصدار الحالي:** `1.3.3`

## ما الذي يقدمه السكربت؟

يحوّل سير تصحيح الأسئلة التي يرفع فيها الطالب ملفًا أو صورة إلى واجهة أسرع وأكثر تركيزًا، بحيث يمكن مشاهدة المرفق والتصحيح والتنقل بين الطلاب والملفات من مكان واحد.

## أبرز المزايا

- عرض مرفق الطالب مباشرة أثناء التصحيح.
- مرجع قابل لتغيير الحجم داخل واجهة المراجعة.
- تصحيح تراكمي سريع.
- اختصارات لوحة مفاتيح تعمل مع تخطيط العربية والإنجليزية.
- تنقل سريع بين مرفقات الطالب وبين الطلاب.
- دعم التنقل بمفاتيح Page Up وPage Down ضمن سير المراجعة.
- تجاوز العناصر التي سبق تصحيحها عند الحاجة.
- عداد للعناصر غير المصححة.
- التكبير والسحب والتدوير للمرفقات.

## طريقة الاستخدام

1. ثبّت السكربت من GreasyFork عبر Tampermonkey.
2. افتح نموذج Microsoft Forms الذي يحتوي على إجابات بمرفقات.
3. ادخل إلى واجهة مراجعة الإجابات والتصحيح.
4. استخدم أدوات العرض والتنقل والاختصارات التي يضيفها السكربت.
5. راجع الدرجة قبل الانتقال أو اعتماد التصحيح.
