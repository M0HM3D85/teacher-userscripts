# Changelog

جميع التغييرات المهمة في **Microsoft Forms - عارض المرفقات والتصحيح السريع** تُسجل هنا.

## [1.3.4] — اسم الطالب المكتوب

- إعطاء الاسم الذي كتبه الطالب في سؤال الاسم أولوية في عنوان عارض المرفقات.
- الاستفادة من بيانات `/responses` التي يحمّلها Microsoft Forms أصلًا لاكتشاف سؤال الاسم وربط الإجابة بالمستجيب الحالي.
- عدم اعتبار `responderName` اسمًا حقيقيًا عندما يكون مجرد اسم المستخدم الذي يسبق `@` في البريد.
- إبقاء بيانات الهوية المؤقتة في الذاكرة فقط دون حفظ أسماء الطلاب أو بريدهم في التخزين المحلي.

## [1.3.3] — Baseline import

- اعتماد الملف الذي سلّمه المطور كخط أساس رسمي للمشروع.
- توحيد بيانات المؤلف والحقوق وروابط المشروع عند الحاجة.
- لا يُعد توحيد الهوية تغييرًا وظيفيًا في السكربت.

> تبدأ سجلات الإصدارات التفصيلية من أول تحديث بعد اعتماد GitHub كمصدر رئيسي.
