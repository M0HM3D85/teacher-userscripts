# Madrasati Assignment Intelligence | مدير الواجبات الذكي

> مدير مساعد لواجبات مدرستي يربط بيانات الطلاب بالدرجات المستوردة ويطبّقها على صفحة الواجب مع ملاحظات وتقارير ومراجعة أكثر أمانًا.

**الإصدار الحالي:** `1.1.7`

## ما الذي يقدمه السكربت؟

يساعد السكربت المعلم في التعامل مع درجات الواجبات عندما تكون البيانات موجودة مسبقًا في ملفات خارجية، مع محاولة مطابقة هوية الطالب بدقة ثم تجهيز الدرجة والملاحظة والحالة قبل تطبيقها داخل مدرستي.

## أبرز المزايا

- مطابقة دقيقة لهوية الطلاب ضمن سير العمل.
- استيراد الدرجات من XLSX وCSV.
- معالجة واضحة لدرجات الصفر عندما لا تكون حالة التسليم متاحة، مع طلب قرار المستخدم بدل التخمين.
- إنشاء ملاحظات تلقائية بحسب حالة التسليم ونسبة الدرجة.
- تطبيق القيم مباشرة في خانات مدرستي المستهدفة.
- حفظ أكثر أمانًا مع مراحل مراجعة قبل الاعتماد النهائي.
- تقارير وتحليل تساعد على مراجعة نتيجة التطبيق.
- دعم صفحة الواجبات وصفحة الطلاب المستخدمة في المطابقة.

## طريقة الاستخدام

1. ثبّت السكربت عبر Tampermonkey.
2. افتح صفحة الواجبات المدعومة في مدرستي.
3. جهّز ملف الدرجات بصيغة XLSX أو CSV حسب سير العمل المستخدم.
4. استورد الملف واترك السكربت يطابق الطلاب ويجهز النتائج.
5. راجع حالات الصفر والملاحظات وأي عناصر غير محسومة قبل التطبيق والحفظ النهائي.
