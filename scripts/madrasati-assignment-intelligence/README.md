# Madrasati Assignment Intelligence | مدير الواجبات الذكي

**الإصدار الحالي:** `1.1.7`

مدير واجبات مدرستي: هوية دقيقة للطلاب، استيراد درجات XLSX/CSV، قرار إلزامي لدرجات الصفر عند غياب حالة التسليم، ملاحظات تلقائية حسب الحالة ونسبة الدرجة، تطبيق مباشر في خانات مدرستي، حفظ آمن وتقارير وتحليل.

## المواقع المستهدفة

- `https://schools.madrasati.sa/Teacher/Assignments/*`
- `https://schools.madrasati.sa/SchoolManagment/Actions/MyStudents*`
