# Forms Smart Results Analyzer | محلل نتائج فورمز الذكي

> منصة تحليل تربوي لنتائج Microsoft Forms تعمل مباشرة داخل صفحة النموذج وتحوّل النتائج إلى مؤشرات وتقارير تساعد المعلم على القراءة واتخاذ القرار.

**الإصدار الحالي:** `0.3.0`

## ما الذي يقدمه السكربت؟

يضيف السكربت طبقة تحليل متقدمة داخل Microsoft Forms بدل الاكتفاء بعرض الاستجابات الخام أو نقل البيانات يدويًا إلى أدوات أخرى. الهدف هو تحويل نتائج الاختبار إلى قراءة تربوية أوضح للصف والمهارات والأسئلة.

## أبرز المزايا

- عرض التقديرات والمؤشرات الأساسية للنتائج.
- استخراج المهارات تلقائيًا من `Subtitle` عند استخدامها في بناء الأسئلة.
- مصفوفة إتقان للمهارات.
- تحديد التدخلات والطلاب أو المهارات التي تحتاج متابعة.
- تحليل حسب الفصول والشعب عند توفر البيانات المناسبة.
- مؤشرات لجودة الاختبار.
- تحليل المشتتات في أسئلة الاختيار.
- مقارنات وتقارير متعددة داخل بيئة التحليل.
- توحيد عرض الأرقام في نظام التقارير بالأرقام الإنجليزية.

## طريقة الاستخدام

1. ثبّت السكربت من GreasyFork عبر Tampermonkey.
2. افتح النموذج المطلوب في Microsoft Forms من صفحة التصميم المدعومة.
3. انتقل إلى النتائج/الاستجابات حسب سير العمل المعتاد.
4. افتح أدوات التحليل التي يضيفها السكربت وراجع المؤشرات والتقارير المطلوبة.
