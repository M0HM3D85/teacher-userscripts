# M85 Noor Grades Assistant V2.4

> مساعد لتعبئة درجات الطلاب في نظام نور مع أوضاع إدخال مرنة وأدوات مراجعة تساعد على اكتشاف الأخطاء قبل الاعتماد.

**الإصدار الحالي:** `2.4`

## ما الذي يقدمه السكربت؟

يعمل السكربت داخل صفحات نظام نور المدعومة لتقليل العمل اليدوي عند تعبئة الدرجات، مع أدوات تساعد على الاستدعاء والإدخال والمراجعة والتنقل إلى الحالات التي تحتاج انتباهًا.

## أبرز المزايا

- زر استدعاء لتشغيل أدوات المساعد في الصفحة المناسبة.
- وضع كامل ووضع جزئي بحسب نطاق الدرجات المطلوب التعامل معه.
- تعبئة منظمة للدرجات ضمن الحقول المستهدفة.
- نسخ تقرير للمراجعة أو الاحتفاظ بنتيجة العملية.
- الانتقال إلى الأخطاء أو الحالات التي تحتاج مراجعة.
- إظهار أسماء الطلاب ضمن سير العمل لتقليل أخطاء الصفوف المتشابهة.
- تجاهل الصفر اليساري عند التعامل مع القيم التي تتطلب ذلك.

## طريقة الاستخدام

1. ثبّت السكربت عبر Tampermonkey.
2. افتح صفحة الدرجات المطلوبة في نظام نور.
3. شغّل المساعد من زر الاستدعاء الذي يظهر في الصفحة المدعومة.
4. اختر الوضع المناسب ونفّذ التعبئة.
5. راجع التقرير والحالات المشار إليها قبل الحفظ النهائي في نور.
