# Changelog

جميع التغييرات المهمة في **مدرستي - مصمم الجدول الدراسي** تُسجل هنا.

## [2.0.0] — 2026-09-24

### إعادة بناء تجربة الاستخدام

- توحيد تجربة Tampermonkey مع إضافة المتصفح `0.2.0` قدر الإمكان.
- استبدال زر التشغيل العائم بشريط مدمج فوق جدول مدرستي.
- إضافة شاشة ترحيب لأول استخدام ونافذة «طريقة الاستخدام».
- اعتماد مساحة عمل شبه كاملة الشاشة مع إعدادات جانبية ومعاينة كبيرة.
- تحديث الهوية البصرية واعتماد الأيقونة الجديدة داخل الواجهة والجدول النهائي.

### الجدول والمعاينة

- دعم جدول المعلم وجدول الطالب ضمن نفس الواجهة الجديدة.
- إبقاء تنظيف `متزامن` و`غير متزامن` من مسمى مادة الطالب.
- إضافة خيار إظهار شعار مصمم الجدول الدراسي افتراضيًا في الجدول النهائي مع إمكانية إخفائه.
- الإبقاء على دعم الشعار المخصص اختياريًا.
- إضافة تذييل: «تم استخراج الجدول بواسطة مصمم الجدول الدراسي» مع تاريخ الاستخراج.
- توحيد الأرقام في المخرجات إلى الأرقام الإنجليزية.

### الأوقات

- تحويل إدخال الأوقات من نص حر إلى حقول وقت منظمة لبداية ونهاية كل حصة.
- إضافة تعبئة تلقائية لجدول المعلم اعتمادًا على وقت البداية ومدة الحصة ومدة الفاصل.
- السماح بتعديل كل حصة يدويًا بعد التعبئة التلقائية.

### التصدير

- إعادة تنفيذ PNG محليًا داخل السكربت دون `html2canvas` أو أي مكتبة JavaScript خارجية.
- الإبقاء على الطباعة / PDF وExcel والنسخ.
- تحسين رسائل النجاح والخطأ داخل الواجهة.

### الخصوصية والهوية

- لا يتم تحميل رمز برمجي بعيد لتشغيل السكربت.
- تتم معالجة الجدول محليًا داخل المتصفح.
- نافذة «حول الأداة» تعرض X وSnapchat فقط، دون GitHub أو GreasyFork.

### ملاحظة حول رقم الإصدار

الإصدار السابق للـUserscript كان `1.4.1`، لذلك تم اعتماد `2.0.0` بدل خفض الرقم إلى `0.2.0`. هذا الإصدار متوافق وظيفيًا ومرئيًا مع Browser Extension `0.2.0`.

## [1.4.1] — Baseline import

- لا يُعد توحيد الهوية تغييرًا وظيفيًا في السكربت.
