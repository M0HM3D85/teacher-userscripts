# مدرستي - مصمم الجدول الدراسي

> يحوّل جدول المعلم أو الطالب في مدرستي إلى نسخة مرتبة وقابلة للتخصيص والمعاينة والطباعة والحفظ والتصدير.

## الإصدارات الحالية

- **Tampermonkey / GreasyFork:** `2.0.0`
- **Browser Extension (Chrome / Edge):** `0.2.0`

> ملاحظة: رقم إصدار Tampermonkey استمر تصاعديًا من `1.4.1` إلى `2.0.0` حتى لا يحدث خفض للإصدار في GreasyFork. أما واجهة ووظائف الإصدار فهي متوافقة مع إضافة المتصفح `0.2.0`.

## ما الجديد في 2.0.0؟

أُعيد بناء تجربة الاستخدام لتتوافق مع نسخة الإضافة، مع إبقاء الفروق التقنية الخاصة بكل منصة فقط.

- شريط مدمج فوق جدول مدرستي بدل الزر العائم.
- شاشة ترحيب لأول استخدام مع شرح مختصر للخطوات.
- مساحة عمل شبه كاملة الشاشة بواجهة عربية RTL.
- لوحة إعدادات منظمة ومعاينة كبيرة مستقلة.
- قراءة جدول المعلم وجدول الطالب تلقائيًا من الصفحات المدعومة.
- تخصيص بيانات الجدول والمظهر والعناصر الظاهرة.
- حقول منظمة لأوقات الحصص: بداية ونهاية لكل حصة.
- تعبئة سريعة لأوقات جدول المعلم انطلاقًا من وقت البداية ومدة الحصة والفاصل.
- شعار مصمم الجدول الدراسي يظهر افتراضيًا في الجدول النهائي ويمكن إخفاؤه.
- دعم شعار مخصص اختياري.
- تذييل للجدول النهائي يوضح أن الجدول تم استخراجه بواسطة مصمم الجدول الدراسي مع تاريخ الاستخراج.
- تصدير PNG محليًا دون الاعتماد على مكتبة خارجية.
- الطباعة والحفظ PDF.
- التصدير إلى Excel.
- نسخ الجدول.
- حفظ التفضيلات محليًا داخل المتصفح عند اختيار المستخدم ذلك.
- توحيد الأرقام في المخرجات إلى الأرقام الإنجليزية.
- تنظيف `متزامن` و`غير متزامن` من مسمى مادة الطالب عند ظهورها كإضافة في نهاية الاسم.

## طريقة الاستخدام

1. ثبّت السكربت عبر Tampermonkey.
2. افتح صفحة جدول المعلم أو الطالب في مدرستي.
3. سيظهر شريط **مصمم الجدول الدراسي** مباشرة فوق الجدول.
4. اضغط **فتح مصمم الجدول**.
5. عدّل البيانات والمظهر والأوقات ثم راجع المعاينة.
6. صدّر النتيجة بصيغة PNG أو PDF أو Excel أو استخدم النسخ.

## الخصوصية

- تتم قراءة ومعالجة بيانات الجدول محليًا داخل المتصفح.
- لا يرسل السكربت محتوى الجدول إلى خوادم المطور.
- لا توجد إعلانات أو تحليلات سلوكية أو تتبع للمستخدم.
- قد تُحفظ تفضيلات المستخدم محليًا في المتصفح لتسهيل الاستخدام لاحقًا.
