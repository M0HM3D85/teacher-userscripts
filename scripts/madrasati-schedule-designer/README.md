# مدرستي - مصمم الجدول الدراسي الاحترافي

> يحوّل جدول المعلم أو الطالب في مدرستي إلى نسخة مرتبة قابلة للتخصيص والطباعة والحفظ والتصدير.

**الإصدار الحالي:** `1.4.1`

## ما الذي يقدمه السكربت؟

يقرأ الجدول الدراسي من صفحة مدرستي المدعومة ثم يعيد تقديمه في واجهة تصميم أكثر وضوحًا، مع أدوات تساعد على إنتاج نسخة مناسبة للطباعة أو الجوال أو الحفظ كملف.

## أبرز المزايا

- دعم جدول المعلم وجدول الطالب في الصفحات المستهدفة.
- تنظيف مسميات المواد وإزالة الإضافات غير المطلوبة مثل `متزامن` و`غير متزامن` من اسم المادة.
- تخصيص بيانات الجدول والعناصر الظاهرة في التصميم.
- تجهيز الجدول للطباعة والحفظ بصيغة PDF.
- حفظ الجدول كصورة PNG.
- تصدير البيانات إلى Excel.
- نسخ الجدول بحسب خيارات الواجهة.
- إبقاء وقت الحصة منظمًا مع رقم الحصة بدل تكراره داخل كل مادة.

## طريقة الاستخدام

1. ثبّت السكربت من GreasyFork عبر Tampermonkey.
2. افتح جدول المعلم أو الطالب في مدرستي.
3. افتح واجهة مصمم الجدول التي يضيفها السكربت.
4. عدّل البيانات وخيارات العرض ثم حدّث المعاينة.
5. اختر الطباعة/PDF أو PNG أو Excel أو النسخ حسب الحاجة.
