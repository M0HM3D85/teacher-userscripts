# ZipGrade Smart Student Manager

> أداة ذكية لإدارة طلاب ZipGrade واستيرادهم، مع مدقق مدمج لنتائج الاختبارات قبل تصديرها إلى محلل النتائج.

**الإصدار الحالي:** `0.9.3`

## ما الذي يقدمه السكربت؟

يجمع السكربت الآن ثلاثة مسارات في أداة واحدة:

1. **الاستيراد الذكي للطلاب** من Excel/CSV مع ربط مرن للأعمدة وفحص البيانات قبل الاستيراد.
2. **إدارة الطلاب** من نفس الصفحة: تعديل بيانات الطالب والتنقل بين الطلاب، مع إمكانية حذف الطالب دون الحاجة للرجوع إلى صفحته الأصلية.
3. **مدقق الاختبار** داخل صفحات نتائج ZipGrade قبل تصدير ملف النتائج للمحلل.

## أبرز المزايا

- استيراد جماعي لبيانات الطلاب من Excel/CSV.
- دعم `Student ID` و`External Ref` والفصل والاسم.
- إدارة وتعديل بيانات الطلاب من واجهة واحدة.
- حذف الطالب من داخل مدير الطلاب مع تأكيد وتحقق بعد الحذف.
- واجهة عربية/إنجليزية في إدارة الطلاب.
- فحص نتائج الاختبار اعتمادًا على **Full Format CSV** من ZipGrade.
- اعتماد `CustomID / External Ref` كحساب الطالب الذي يمكن ربطه لاحقًا ببريد Microsoft Forms.
- اكتشاف الطلاب أو السجلات المكررة والتنبيه بها دون حذف تلقائي.
- اكتشاف الحساب المفقود أو غير الصالح للربط.
- اكتشاف التظليل المتعدد وتحديد **اسم الطالب ورقم السؤال** ليتخذ المعلم القرار بعد مراجعة الورقة.
- قراءة الفصول المسندة للاختبار تلقائيًا، وكشف أي **استجابة لطالب من خارج الفصول المشمولة** مع قرار مراجعة يدوي قبل التصدير.
- قراءة قائمة الطلاب **مرة واحدة لكل فحص** وتحديد طلاب الفصول المشمولة الذين **لا توجد لهم استجابة**، كتنبيه معلوماتي لا يمنع التصدير.
- عرض الإجابات الفارغة والدرجات الجزئية مع اسم الطالب والأسئلة المتأثرة.
- تلوين صف الطالب نفسه بحسب نوع الملاحظة بدل الاعتماد على Item Analysis فقط.
- التنقل بين أوراق الطلاب: السابق، التالي، والطالب التالي الذي يحتاج مراجعة.
- البحث الفوري عن الطالب بالاسم أو `Student ID` أو البريد داخل نتائج الاختبار.
- تصفية جدول النتائج حسب الفصل والحالة، بما في ذلك خارج الفصول وبلا استجابة.
- فرز النتائج حسب الاسم أو الفصل أو الدرجة أو النسبة أو وقت التصحيح أو `Student ID`، تصاعديًا أو تنازليًا.
- أدوات البحث والتصفية والفرز تغيّر العرض فقط ولا تغيّر بيانات الاختبار أو ملف **Full XLSX**.
- حماية تصدير **Full Format XLSX** حتى تنتهي المشاكل المانعة وتتم مراجعة الحالات المطلوبة.

## ألوان مدقق الاختبار

- **أحمر:** تكرار أو مشكلة في الحساب/الربط أو استجابة من خارج الفصول المشمولة.
- **برتقالي:** تظليل متعدد يحتاج قرار المعلم.
- **أصفر:** إجابة فارغة.
- **أزرق:** درجة جزئية.
- **أخضر:** تمت مراجعة حالة تحتاج قرارًا واعتمادها كما هي.
- **تنبيه مستقل بلا تلوين صف:** طالب من الفصول المشمولة لا توجد له استجابة؛ لا يمنع التصدير.

## طريقة الاستخدام

### إدارة الطلاب

1. افتح صفحة الطلاب في ZipGrade.
2. استخدم **الاستيراد الذكي** لإضافة قائمة طلاب من Excel/CSV، أو افتح **إدارة الطلاب** لتعديل البيانات الحالية.
3. من شاشة إدارة الطالب يمكنك الحفظ أو حذف الطالب بعد رسالة تأكيد.

### مدقق الاختبار

1. افتح صفحة نتائج الاختبار `/quiz/.../all/`.
2. ينفذ السكربت الفحص اعتمادًا على Full Format CSV ويطابق النتائج مع صفوف الطلاب.
3. يقرأ فلاتر الفصول المرتبطة بالاختبار، ثم يقرأ قائمة الطلاب مرة واحدة لتدقيق نطاق الفصول واكتشاف الطلاب بلا استجابة.
4. راجع الصفوف الملونة والتنبيهات التفصيلية.
5. في حالات التظليل المتعدد أو الاستجابة من خارج الفصول، راجع الحالة وقرر هل تعدلها في ZipGrade أم تعتمدها كما هي.
6. بعد اكتمال المراجعة استخدم **Full XLSX الجاهز للمحلل**.

## التكامل القادم

ملف **Full Format XLSX** الناتج من ZipGrade سيكون مصدر النتائج الورقية في **Forms Smart Results Analyzer**، مع استخدام:

`CustomID في ZipGrade = البريد الإلكتروني في Microsoft Forms`

كمفتاح موحد لدمج الطلاب الذين اختبروا ورقيًا وإلكترونيًا في تقرير واحد.
