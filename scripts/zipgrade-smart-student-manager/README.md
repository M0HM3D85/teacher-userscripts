# ZipGrade Smart Student Manager

> أداة ثنائية اللغة لاستيراد الطلاب إلى ZipGrade بسرعة ثم إدارة بياناتهم من الصفحة نفسها بدل تكرار العمل اليدوي.

**الإصدار الحالي:** `0.7.0`

## ما الذي يقدمه السكربت؟

يجمع السكربت بين مسارين في أداة واحدة: استيراد ذكي لبيانات الطلاب من ملفات Excel/CSV، ثم إدارة وتعديل بيانات الطلاب مباشرة داخل صفحات ZipGrade المستهدفة.

## أبرز المزايا

- استيراد جماعي لبيانات الطلاب من Excel/CSV.
- تقليل الحاجة لإضافة الطلاب واحدًا واحدًا.
- إدارة وتعديل بيانات الطلاب من داخل الصفحة.
- دعم واجهة ثنائية اللغة ضمن سير العمل.
- مراجعة البيانات قبل تنفيذ الاستيراد لتقليل الأخطاء.
- مناسب لإعادة استخدام قوائم الطلاب الموجودة بدل إعادة كتابتها يدويًا.

## طريقة الاستخدام

1. ثبّت السكربت من GreasyFork عبر Tampermonkey.
2. افتح صفحة الطلاب أو صفحة الاستيراد في ZipGrade.
3. استخدم أداة الاستيراد لقراءة ملف الطلاب أو أدوات الإدارة لتعديل البيانات الموجودة.
4. راجع الأسماء والحقول قبل اعتماد الاستيراد أو التعديلات.
