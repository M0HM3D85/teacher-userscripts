# Changelog

## [0.9.5] — تحسين كشف التظليل المتعدد

- إصلاح كشف التظليل المتعدد في أسئلة التقدير الرقمية/المقالية التي تستخدم خيارات `0 / نصف / 1`.
- اعتبار تراكيب مثل `01` و`0½` و`½1` و`0 + 1` تظليلًا متعددًا يحتاج مراجعة.
- الإبقاء على `0.5` و`0,5` و`½` و`1/2` كإجابة نصف واحدة، لتجنب الإنذارات الكاذبة.
- تمرير المفتاح الأساسي للسؤال إلى كاشف التظليل لتمييز مقياس الدرجات الرقمي بأمان.
- الحفاظ على جميع وظائف v0.9.4 ومفاتيح التخزين الحالية للمراجعات والتنقل.
- توحيد `@homepageURL` مع سياسة هوية المستودع.

جميع التغييرات المهمة في **ZipGrade Smart Student Manager** تُسجل هنا.

## [0.7.0] — Baseline import

- اعتماد الملف الذي سلّمه المطور كخط أساس رسمي للمشروع.
- توحيد بيانات المؤلف والحقوق وروابط المشروع عند الحاجة.
- لا يُعد توحيد الهوية تغييرًا وظيفيًا في السكربت.
