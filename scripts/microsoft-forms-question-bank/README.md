# Microsoft Forms - بنك الأسئلة والإدخال الجماعي

> أدوات لإدخال عدد كبير من الأسئلة إلى Microsoft Forms بصورة أسرع، مع دعم ملفات البيانات والمهارات وبيانات الطالب والمساعد الذكي.

**الإصدار الحالي:** `0.7.0`

## ما الذي يقدمه السكربت؟

يساعد السكربت في تقليل العمل اليدوي عند بناء الاختبارات في Microsoft Forms، خصوصًا عند تجهيز بنك كبير من الأسئلة أو إعادة استخدام محتوى موجود في ملفات خارجية.

## أبرز المزايا

- إدخال جماعي لعدد كبير من الأسئلة إلى Microsoft Forms.
- دعم أنواع الأسئلة التي يدعمها سير عمل السكربت، بما فيها أسئلة الاختيار.
- استخدام المهارات كعنوان فرعي `Subtitle` للأسئلة.
- تصنيف مهارات الأسئلة الموجودة مسبقًا.
- دعم بيانات الطالب ضمن سير بناء النموذج.
- استيراد من Excel وCSV وTXT.
- مساعد AI ضمن الوظائف التي يوفرها السكربت.
- واجهة تساعد على مراجعة البيانات قبل تنفيذ الإدخال الجماعي.

## طريقة الاستخدام

1. ثبّت السكربت من GreasyFork عبر Tampermonkey.
2. افتح نموذج Microsoft Forms من صفحة التصميم المدعومة.
3. افتح أدوات بنك الأسئلة التي يضيفها السكربت.
4. أدخل الأسئلة مباشرة أو استورد الملف المناسب.
5. راجع الأسئلة والخيارات والمهارات قبل بدء الإدخال الجماعي.
