# راصد الطلاب | مدرستي + نور

**الإصدار الحالي:** `1.9.1`

راصد دقيق لبيانات الطلاب من صفحات الطلاب المطلوبة فقط في مدرستي ونور: استخراج دقيق، مدرسة نور كاملة، نسخ مقارنة ببصمة تحقق، مقارنة شاملة محافظة، سجل زمني، ومركز مراجعة يدوية.

## المواقع المستهدفة

- `https://schools.madrasati.sa/SchoolManagmentReports/StudentInfo/ClassStudentInfo/*`
- `https://noor.moe.gov.sa/Noor/EduWavek12Portal/ReportPages/StudntNamesReport.aspx*`
