# Fares+ | فارس+

> تحسين شامل لتجربة نظام فارس يضيف أدوات عملية لتسريع إدارة أنشطة التطوير المهني والاستيراد والتقارير.

**الإصدار الحالي:** `1.1.0`

## ما الذي يقدمه السكربت؟

يعمل **Fares+ | فارس+** داخل صفحات نظام فارس المستهدفة ويضيف طبقة أدوات تساعد على إنجاز الأعمال المتكررة بصورة أسرع وأكثر تنظيمًا، مع إبقاء المستخدم داخل النظام نفسه قدر الإمكان.

## أبرز المزايا

- إدارة أنشطة التطوير المهني من واجهة أكثر عملية.
- استيراد البيانات من ملفات Excel بدل الإدخال المتكرر يدويًا.
- التعامل مع الشهادات بصيغ PDF والصور ضمن سير العمل.
- تحليل اختياري عبر Gemini عند استخدام الميزة المخصصة لذلك.
- حفظ مسودات للعودة إلى العمل لاحقًا.
- إنشاء تقارير تساعد في المراجعة والمتابعة.
- أدوات مساعدة لتقليل النقرات والأعمال المتكررة داخل فارس.

## طريقة الاستخدام

1. ثبّت السكربت من GreasyFork عبر Tampermonkey.
2. افتح صفحة فارس المدعومة.
3. استخدم الأدوات التي يضيفها السكربت داخل الصفحة بحسب المهمة المطلوبة.
4. راجع البيانات قبل الحفظ النهائي، خصوصًا عند الاستيراد أو استخدام التحليل الاختياري.
