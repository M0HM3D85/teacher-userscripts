# Fares+ | فارس+

> تحسين شامل لتجربة نظام فارس يضيف أدوات عملية لتسريع إدارة أنشطة التطوير المهني والاستيراد والتقارير.

**الإصدار الحالي:** `1.1.1`

**حالة الإصدار:** تم تأكيد عودة اعتماد المسودات إلى سجلات فارس بنجاح بعد التحديث إلى 1.1.1 (تأكيد المستخدم بتاريخ 2026-11-02). الإصدار معتمد حاليًا دون تعديل إضافي على مسار الاعتماد.

## ما الذي يقدمه السكربت؟

يعمل **Fares+ | فارس+** داخل صفحات نظام فارس المستهدفة ويضيف طبقة أدوات تساعد على إنجاز الأعمال المتكررة بصورة أسرع وأكثر تنظيمًا، مع إبقاء المستخدم داخل النظام نفسه قدر الإمكان.

## أبرز المزايا

- إدارة أنشطة التطوير المهني من واجهة أكثر عملية.
- استيراد البيانات من ملفات Excel بدل الإدخال المتكرر يدويًا.
- التعامل مع الشهادات بصيغ PDF والصور ضمن سير العمل.
- تحليل اختياري عبر Gemini عند استخدام الميزة المخصصة لذلك.
- حفظ مسودات للعودة إلى العمل لاحقًا.
- إنشاء تقارير تساعد في المراجعة والمتابعة.
- أدوات مساعدة لتقليل النقرات والأعمال المتكررة داخل فارس.

## طريقة الاستخدام

1. ثبّت السكربت من GreasyFork عبر Tampermonkey.
2. افتح صفحة فارس المدعومة.
3. استخدم الأدوات التي يضيفها السكربت داخل الصفحة بحسب المهمة المطلوبة.
4. راجع البيانات قبل الحفظ النهائي، خصوصًا عند الاستيراد أو استخدام التحليل الاختياري.

## فحص التوافق عند تعطل اعتماد المسودات

- **نسخة 1.1.1:** إصلاح توقف الاعتماد المبكر الناتج عن استدعاء دالة تشخيص قديمة غير موجودة (`clearCommitDebug`). لم يتم تعديل تنسيق المسودات أو حذف بياناتها.
- يمكن تثبيت [فاحص توافق فارس+ (قراءة فقط)](./fares-plus-audit.user.js) كـ Userscript منفصل مؤقتًا، بجانب فارس+.
- افتح صفحة فارس الرئيسية واضغط **فحص فارس+** ثم **تنزيل تقرير JSON**.
- انتقل إلى صفحة **أنشطة التطوير المهني**، وافتح قسم الأنشطة، وأعد تنزيل التقرير مرة أخرى. إذا استمر التعطل بعد تحديث فارس+، أنشئ التقرير قبل محاولة اعتماد مسودة واحدة، ثم بعدها.
- الفاحص لا يضغط أزرار «إضافة» أو «حفظ» ولا يرسل أي طلبات؛ ولا يقرأ أسماء الموظفين أو قيم حقول الأنشطة أو محتوى المسودات. يسجل وجود عناصر الصفحة وأعداد المسودات ومرحلة العملية المعلقة فقط.
- لا تستخدم اعتماد الكل قبل التأكد من نجاح **مسودة واحدة**؛ تحقق من ظهور النشاط في سجلات فارس قبل متابعة البقية.
- احذف فاحص التوافق من Tampermonkey بعد الانتهاء من التشخيص، ولا تحذف المسودات أو بيانات الموقع لحل المشكلة.
