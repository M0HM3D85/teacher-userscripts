# قائمة ترحيل السكربتات الحالية

تُستخدم هذه القائمة عند نقل أي سكربت قائم من الملفات المحلية/GreasyFork إلى هذا المستودع.

## لكل سكربت

- [ ] تحديد آخر نسخة مستقرة فعلية.
- [ ] التأكد من اسم السكربت ورقم `@version`.
- [ ] مقارنة نسخة الملف مع النسخة المنشورة في GreasyFork عند الحاجة.
- [ ] إنشاء مجلد باسم ثابت بالإنجليزية داخل `scripts/`.
- [ ] حفظ الكود باسم ينتهي بـ `.user.js`.
- [ ] إنشاء/تحديث `README.md`.
- [ ] إنشاء/تحديث `CHANGELOG.md`.
- [ ] إدخال السكربت في `scripts/catalog.json`.
- [ ] تشغيل `Validate Userscripts` بنجاح.
- [ ] اختبار السكربت فعليًا في الموقع المستهدف.
- [ ] دمج التغييرات إلى `main`.
- [ ] ربط صفحة GreasyFork الحالية برابط Raw من `main`.
- [ ] اختبار تحديث Tampermonkey بدون إعادة تثبيت.
