# Shared Modules

هذا المجلد مخصص مستقبلًا للأجزاء المشتركة بين سكربتات المشروع، مثل:

- مكونات الواجهة والتنبيهات.
- التخزين والإعدادات.
- أدوات التصدير والطباعة.
- معالجة النصوص والأرقام العربية/الإنجليزية.
- عناصر تعريف المطور والتذييل الموحد.

## قاعدة مهمة

لا ننقل كودًا إلى `shared/` لمجرد أنه متشابه. ننقله فقط عندما يوجد استخدام فعلي في أكثر من سكربت ويكون فصلُه لا يعرّض السكربتات لمشكلات اعتماد أو لسياسات GreasyFork الخاصة بالكود الخارجي.

الأولوية دائمًا أن يبقى ملف `.user.js` المنشور واضحًا وقابلًا للفحص.
